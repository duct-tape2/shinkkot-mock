# 신꽂 - 편의점 신상 재고 맵 (Mock Demo)

> 한국 편의점 신상품 / 한정 상품 / 품절 대란템 통합 검색 프로토타입

**⚠️ Mock prototype**: 실제 편의점 API 제휴 없음. UI/UX와 수익 모델 검증용 데모.

## 라이브 데모

https://duct-tape2.github.io/shinkkot-mock/

(모바일에서 보면 더 자연스러움 - 모바일 first 디자인)

## 컨셉

- 편의점별 앱(GS25, CU, 세븐일레븐, 이마트24)을 따로 열어야 하는 불편 해결
- 신상품, 한정 상품, 품절 대란템을 한 곳에서 검색
- 근처 점포 재고 + 재입고 알림

## 수익 모델 가설

1. **프리미엄 알림 (3,900원/월)** - 특정 상품/지역 알림 무제한
2. **제휴 광고** - 편의점이 신상품 노출 자리 구매
3. **트렌드 리포트** - 식음료 회사 대상 월간 보고서 (월 290,000원)

## 현재 진행 상황

- ✅ Mock UI/UX (HTML/JS, single page)
- ✅ 더미 데이터 (강남구 GS25 6개 점포 × 1상품)
- ✅ 알림 mock interaction
- ❌ 실제 편의점 데이터 API (제휴 필요)
- ❌ 결제 시스템
- ❌ 모바일 앱

## 누구를 위한가

- 신상 디저트/한정 상품 찾는 10-30대 소비자
- 매장 마케팅 담당자 (제휴 광고 채널)
- 식음료 트렌드 분석가 (월간 리포트)

## 다음 액션 (사용자 결정 필요)

1. **편의점 본사 제휴 영업** - GS25 → CU → 7-11 순서, 최소 1개 브랜드 필수
2. **인스타/X에 mock 데모 공유** → 실제 사용자 반응 측정
3. **사전 등록 페이지 (Polar.sh)** - 베타 출시 시 알림 받기

## 왜 이게 가능한가

- 편의점 신상품 출시 주기 = 매주 (지속적 수요)
- 한국 편의점 시장 = 5조원/년
- 신상 디저트 검색량 (네이버 트렌드) = 월 300만+
- 경쟁자: 편의점 공식 앱은 분리됨, 통합 검색 없음

## 빠른 출시 path

1. **편의점 1개 + 강남구 1개** mock data 확장
2. **사전 등록 페이지** = 베타 100명 모집
3. **본사 제휴 영업 자료**로 사전 등록 100명을 증거 사용
4. **공식 API 받으면** → 실제 데이터로 확장
